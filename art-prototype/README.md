# 三国·孤军行：美术样板 v0.1

临时工作名，用于验证三国卡牌肉鸽的像素美术方向。不是完整游戏，也尚未接入微信小游戏运行时。

## 预览

打开 `index.html`。点击三张卡牌可以查看选择状态；结束回合按钮仅说明预览范围。

- `battle-preview.png`：420 像素宽的竖屏界面截图。
- `battle-preview-375.png`：375 像素宽的窄屏截图。
- `assets/`：5 张 PixelLab 原始透明 PNG，角色 128×128，图标 64×64。
- `assets/manifest.json`：PixelLab 生成任务 ID 和下载链接。
- `prompts.md`：生成提示词和参数。

## 美术约定

青玉、旧金、宣纸色界面；赵云使用银青色，黄巾兵使用土黄褐色。素材按像素方式显示，中文名称和描述由 HTML 文本呈现。角色在界面中水平翻转，以朝向战场中央；源图片保持不变。

本轮通过用户指定的 PixelLab MCP `create_image_pixflux` 生成 5 张素材，每张返回消耗 1 次生成。界面、山形背景和布局由 HTML/CSS 构建，没有使用其他图像生成器。

## 验证与边界

- 5 张图片均正常加载，无页面脚本错误。
- 卡牌选择状态能够切换。
- 375 像素屏幕宽度下无横向溢出；页面可纵向滚动。
- 已检查桌面 Chromium 截图；尚未做微信环境或手机真机验证。
- 卡牌效果、生命值、节点路线均为展示设定，未实现战斗结算。
- 第一轮独立生成尚未做参考图锁定。赵云的身份特征、枪形和兵书材质仍可进一步精修；后续动画和批量素材应在风格确定后制作。
