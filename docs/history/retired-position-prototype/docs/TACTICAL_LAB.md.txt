# 三张为阵 · 破阵试验场

独立玩法实验。桌面默认进入，浏览器地址为 `/battlefield.html`；右上角可返回算分构筑版。三个位置、三个武将、盾兵和弓手，一个敌阵，没有商店与成长。

战前用箭头自由排位。开战后每回合4军令，每位武将先行动一次；攻击、技能、换位各耗1军令。换位不会清除已行动状态。三回合内消灭敌军且三将存活才算成功。

- 张飞：先锋喝退，2伤害；后格空则击退，后格有人则双方碰撞各再受2伤害；退到边界再受2。
- 赵云：敌先锋空缺时穿过缺口攻击最后方敌人4伤害，否则最近敌人2伤害；之后与我方先锋交换位置。
- 诸葛亮：让相邻且已经行动的友将恢复待命。消耗诸葛亮本次行动和1军令，友将再次行动另付1军令。
- 普通攻击：最近敌人2伤害。
- 盾兵攻击我方先锋（盾兵仍在先锋时3，后撤后2）；弓手攻击我方后援4。当前目标公开显示，随我方站位更新。

允许撤回包括敌方回合，便于比较行动顺序。本实验不存档，重新打开应用会回到初始状态。思路提示默认收起。当前无动作动画与完整美术，不将文字流程跑通视作乐趣已成立。

验证：5项核心测试；浏览器分别完成一回合碰撞解法、两回合突袭解法，验证撤回和1280×720布局；macOS打包程序验证通关和返回构筑版。见 `docs/evidence/tactics-*.png`、`tactics-native.json`。Windows现有包仍属于先前构筑迭代，未更新为这个实验。

接下来观察：玩家是否主动调整位置，是否能预判换位后的受击目标，是否愿意撤回尝试另一种解法。一个固定敌阵的最优解仍可能很快被解出；若仅像一次性谜题，需先改善动作取舍再谈接入肉鸽。
