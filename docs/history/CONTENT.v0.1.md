## 锦囊：每张每场一次、每轮总共一张、均消耗 1 军令

| ID | 名称 | 精确定义 |
|---|---|---|
| advance | 顺势 | 选择一张有效点数 ≤8 的己方牌，本轮点数 +1；已为 9 不可选 |
| borrow-banner | 借旗 | 选择一张己方牌和另一种兵种，将其有效兵种改为该兵种；不能选原兵种 |
| regroup | 重整 | 选择两个己方槽位，同时弃掉两张，再按槽位从小到大各抽一张；不计普通换阵次数；余牌不足两张时不可用 |
| star-reading | 观星 | 查看己方余牌堆顶三张；选择其中一张放到堆顶，其余保持原相对顺序；不足三张不可用；确认前不推进状态 |
| fortify | 固守 | 本轮获得 4 护甲，只减少亮阵败北造成的普通伤害 |
| supply | 整军 | 消耗 1 军令后回复 2 军令，故净增加 1；军令上限 4；在满 4 时不可使用 |

持有和槽位操作只在奖励/商店发生；换入一张锦囊后下一场即可用，不允许在战斗中替换。观星查看在付费确认使用后显示，不能退回未使用状态；选择堆顶顺序可在确认前修改，但不能取消该次锦囊消耗。文中“确认前不推进状态”专指排序确认，进入观星子阶段时使用次数和费用已记账并存档。

## 军宝：最多四件，唯一持有，不叠同名

| ID | 名称 | 效果与触发边界 |
|---|---|---|
| spear-tassel | 亮银枪纂 | 亮阵胜出且为连阵或同袍连阵时原始伤害 +2 |
| common-banner | 同袍战鼓 | 亮阵胜出且为同袍或同袍连阵时原始伤害 +2；同花顺可同时触发枪纂 |
| scout-map | 行军图 | 每轮侦察次数上限由 1 变 2；仍每次花 1 军令 |
| white-horse | 白马 | 每轮换阵次数上限由 1 变 2；赵云只免首次费用 |
| tiger-seal | 虎符 | 战势为 3 且亮阵胜出时原始伤害 +2；敌人退让不触发 |
| green-bag | 青囊 | 完成战斗并存活后恢复 3 兵力；在奖励前结算；不得复活已归零玩家 |

效果按“点数兵种修改 → 判型比较 → 胜者加值求和 → 护甲 → 兵力 → 消耗战 → 战斗终止 → 青囊 → 奖励”处理。除青囊外的表内效果没有结束后触发行为。

|---|---|---|---|

## 商店和奖励候选

商店在进入时固定两种不同且未持有锦囊（各 18）、一种未持有军宝（30）与一次恢复 8（12）。池为空则该货架显示售罄，不从已持有内容补齐；候选不足时只展示实际数量。军资不足或生命已满的治疗不可购买。

普通战奖励从未持有锦囊池中无放回抽取最多三种；精英从未持有军宝池中同样抽取。候选不足三种不复制补齐；池为空仍可选军资。替换必须指明被替换的 ID，不把卸下内容自动换成钱。奖励和购买完成时刷新存档，不得重复领取。
