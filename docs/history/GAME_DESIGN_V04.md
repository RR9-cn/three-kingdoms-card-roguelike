# 三国·三张定天下：构筑版 v0.4.0

玩家承诺：六张选三张，通过武将、军宝和永久改牌，逐步组建能打出高攻势的军队。Steam PC 买断方向；当前是离线开发原型，不是正式发行版本。

本版参考《小丑牌》的局内组合与成长思想。可借鉴的是奖励如何改变后续决策、单个简单效果如何共同放大、玩家如何改善随机稳定性；不是复刻扑克对赌或照搬其素材。[LocalThunk 访谈](https://rogueliker.com/balatro-interview/)、[Balatro 官网](https://www.playbalatro.com/)。

## 一局流程

开局核心三选一（关羽、周瑜、刘备） → 战前确认普通/加压 → 六选三出阵，有限次数内累计攻势达标 → 免费征募三选一 → 一次永久整编 → 商店补强 → 下一关。八关全部攻破即胜；出牌用尽仍未达标则失败。最后一关后不再进行奖励与商店。

开局不限制后续招募，关羽开局仍能转成同兵种或低点牌。后续候选使用独立随机流，从未持有组件中抽取，不暗中保送配件。目标体验是在第三关前形成一个可以描述的方向，并开始期待相关奖励；这仍待真人试玩验证。

## 阵牌与战斗

起始牌库36张：枪、骑、弓、谋各1–9。每关洗本局牌库并抽6张；选择3个不同物理ID出阵，按原手牌从左至右计分。每关通常4次出牌、2次换牌；换牌可同时换1–3张。张角关仅3次出牌。白马额外增加一次换牌。

出过或换掉的牌进入弃牌堆，余牌用尽时只洗弃牌堆；不把手中的牌一起洗回。每关开始重新洗牌，局内改牌保留。阵牌数不得少于12或多于60。

| 牌型 | 基础兵力 | 基础倍率 |
|---|---:|---:|
| 散阵 | 8 | 1 |
| 合击（含对子） | 16 | 2 |
| 连阵 | 24 | 2 |
| 同袍 | 32 | 3 |
| 同袍连阵 | 45 | 4 |
| 三军同心 | 60 | 5 |

每升一级，所选牌型基础兵力+10、基础倍率+1。牌型从弱至强取最高适用项，点数不环绕。兵书允许三个不同点数排序后相邻间隔至多2构成连阵；同兵种时为同袍连阵。

## 结算顺序

1. 取牌型与本局等级的基础兵力、倍率。
2. 每张出牌依次加入点数与永久强化，再执行逐牌组件（刘备、黄忠、貂蝉、青龙刀）。
3. 张飞重触发第一张对子牌；诸葛亮重触发最右出牌。重复时重新执行该牌的点数、强化与逐牌效果，不能再次触发自身形成无限循环。两个重复来源可各增加一次。
4. 按上方组件槽从左至右结算整手效果，加倍率与乘倍率顺序有意义。关羽、赵云本次先成长再作用到本手；成长常驻在该组件上，不要求以后每手都满足条件才能享用累积倍率。
5. 最终攻势为向下取整的「兵力×倍率×关卡修正」。累加后先判达标，再判次数耗尽。出牌结果需要点击下一手/收战果确认，不能双击同一位置连续出牌。

预览使用同一计算函数的只读结果，不推进随机、不提前写回成长。UI显示逐步来源与可跳过的计分动画。

算例：关羽、张飞、黄忠、青龙刀，出枪7、骑7、弓2。基础16兵力×2倍率；第一张7重复一次，所以三次高点计分贡献75兵力，2再贡献2，总93兵力。青龙刀三次提供6倍率、关羽本次成长1，总9倍率；本手837攻势。

## 构筑与经济

20个组件共享5个槽。效果和标价以 `packages/content/src/forge.ts` 为唯一运行配置，内容表见 CONTENT。可在战前、战中布阵和商店用箭头调整顺序；出售仅商店允许，返还标价的一半（向下取整），成长丢失。容量满时先选择替换对象；替换不退款。

开局12军资。前7关胜后获得10+剩余出牌次数+利息（每5军资1，上限5）；加压额外+8。征募可跳过拿4，整编可跳过拿3。商店三个固定候选，刷新首次3军资，每次涨1。购买、刷新和奖励行动均由序号验证；资金不足、目标无效或替换未选择，不扣资源、不推进随机。

整编六选一：裁军删一张；募兵复制一张并保留属性、生成新ID；练兵点数+2上限9；精锐每次计分额外+12兵力，可叠加；改编换兵种；研习升级指定牌型。整编只能成功一次，然后进入商店。

## 新旧版本

默认入口为v0.4构筑版；`legacy.html`保留v0.1随机对手版。旧规则在 `docs/history/`、旧代码与测试仍保留，旧存档不覆盖。

新模式 schemaVersion=3，contentVersion=0.4.0，双槽键 `three-card:forge:v4:0/1`。无兼容记录时提示重新开始并保留原记录；不将旧规则存档强行重演成新局。新局不继承成长、改牌或任何永久战斗数值。

## v0.3.1 试玩修订

虎符加压倍率为1.25，低于目标增长1.5。后半程目标提高，不按玩家构筑动态变化。战后征募、整编、商店预告下一关军情；未出牌保留，选中牌展示顺序与实际从左至右结算一致。剩余目标与每手平均所需攻势帮助判断是否值得花换牌。

规则调整使用独立 three-card:forge:v3.1 双槽；旧v2、v3存档保留但不混用新目标。流派的进一步机制差异与武将剧情记忆仍待后续设计和真人复测，本轮不声称已解决重玩欲望。

## 阶段首领

第4关张宝、第8关张角各两阶段：累计攻势达到总目标40%（向上取整）后，下一手使用第二阶段规则。阶段突破不截断伤害、不重置次数，一手足够强仍可直接击杀。加压时阈值随总目标同比提高。阶段与战报自动存档。

张宝第一阶段换牌解除伏击，第二阶段伏击结束，重复上一手牌型攻势减半。张角第一阶段正常计分，第二阶段出牌后、补牌前须留有谋牌才能免除0.6修正。把最后一张谋牌用于计分就失去避雷效果；预览显示准确结果。

首领身份、兵力条、两阶段意图、变招与击败台词让战场状态可见。现阶段使用代码印章与排版，不是新绘制人物美术。旧存档保留，新规则需新征程。
