# Steam 发行准备

当前策略：PC 买断制单人游戏，先做免费试玩章验证玩法，再确定完整版内容与定价。首章暂定《黄巾初起》，不将现有一章原型作为内容已完成的正式商品。

## 商店文案草稿

**短描述**：三张布阵，一念进退。率领赵云穿越黄巾战火，从六张牌中选三张出阵，招募将星、永久改编牌库，在每一段征途中组合属于你的打法。

**试玩内容**：22位常驻将星、八关、六种牌型、四种随机正向整编。支持离线游玩、本地自动存档与键鼠操作。当前为中文开发版；没有成就、Steam Cloud、手柄或 Steam Deck 验证。

美术来自已登记的 PixelLab 生成素材，本轮将星采用文字印章排版，缺少完整武将肖像与部分敌将演出。正式商店截图必须使用完成后的实际游戏画面。

## 发布前清单

- [ ] 确认发行主体、Steamworks 账户、税务与收款信息、应用费用和 AppID。
- [ ] 按官方流程创建 Demo 应用并关联完整游戏；配置包、Depot 与启动项。官方依据：[Demos](https://partner.steamgames.com/doc/store/application/demos)。
- [ ] 将生成式 AI 使用范围、预生成美术、人工修改与资源来源如实填入内容调查；核验可分发权利。官方依据：[Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)。
- [ ] 补齐 Capsule、图标、商店截图、实机预告片和系统需求。当前没有正式商店美术与预告片。
- [ ] Windows x64 实机测试：首次启动、中文字体、100%/125%/150%缩放、键鼠、最小化/失焦、退出恢复、完整胜败、无网络启动。
- [ ] 五位首次接触的玩家试玩：记录是否理解加压、每次决策原因、单轮和全局时长。
- [ ] 完善敌将美术、动作反馈、声音与内容量；测试价格和完整版内容承诺。
- [ ] 审核第三方依赖与许可证，确认发布包保留相应版权文件；评估安装体积和签名。
- [ ] 在 Steam 测试分支上传并验证安装、启动、更新与存档，再提交商店和构建审核。

本次仅完成本地开发和打包，未创建商店、购买应用名额或上传任何文件。Windows 交叉打包不代表 Windows 原生验收。
