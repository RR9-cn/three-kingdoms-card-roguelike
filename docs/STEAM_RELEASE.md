# Steam 发行准备

当前策略：PC 买断制单人游戏。先通过 indienova 开发日志引导玩家到免费 Windows 测试包，完成首轮陌生玩家验证；达到测试门槛后再支付 Steam Direct 费用并创建商店页或 Steam Playtest。具体节奏见 [indienova 宣发与首轮真人测试计划](INDIENOVA_OUTREACH.md)。当前题材验证名为《午夜落槌》，不将现有八场原型作为内容已完成的正式商品。

## 商店文案草稿

**短描述**：午夜开门，从六件来路不明的遗物中选三件成组上拍；邀请怪人举牌、调整收藏目录，把无人问津的破烂炒成天价。

**试玩内容**：12位可自由竞价的活跃贵宾、八场夜拍、六种藏品组合、六种随机定向目录调整。支持离线游玩、本地自动存档与键鼠操作。当前为中文开发版；没有成就、Steam Cloud、手柄或 Steam Deck 验证。

本轮采用 CSS 构建的黑金装饰艺术界面与贵宾剪影，旧三国角色素材不再出现在活跃界面；正式贵宾肖像、诡物拍品与签名买家演出仍未完成。正式商店截图必须使用完成后的实际游戏画面。

## 发布前清单

- [ ] 按 indienova 宣发计划完成 Windows 测试包、首篇开发日志和 6 名陌生玩家测试。
- [ ] 达到理解、重开和构筑记忆门槛后，再决定是否支付 Steam Direct 费用。
- [ ] 确认发行主体、Steamworks 账户、税务与收款信息、应用费用和 AppID。
- [ ] 按官方流程创建 Demo 应用并关联完整游戏；配置包、Depot 与启动项。官方依据：[Demos](https://partner.steamgames.com/doc/store/application/demos)。
- [ ] 将生成式 AI 使用范围、预生成美术、人工修改与资源来源如实填入内容调查；核验可分发权利。官方依据：[Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)。
- [ ] 补齐 Capsule、图标、商店截图、实机预告片和系统需求。当前没有正式商店美术与预告片。
- [ ] Windows x64 实机测试：首次启动、中文字体、100%/125%/150%缩放、键鼠、最小化/失焦、退出恢复、完整胜败、无网络启动。
- [ ] 五位首次接触的玩家试玩：记录是否理解加压、每次决策原因、单轮和全局时长。
- [ ] 完善贵宾、诡物与签名买家美术，补齐动作反馈、声音与内容量；测试价格和完整版内容承诺。
- [ ] 审核第三方依赖与许可证，确认发布包保留相应版权文件；评估安装体积和签名。
- [ ] 在 Steam 测试分支上传并验证安装、启动、更新与存档，再提交商店和构建审核。

本次仅完成本地开发和打包，未创建商店、购买应用名额或上传任何文件。Windows 交叉打包不代表 Windows 原生验收。
