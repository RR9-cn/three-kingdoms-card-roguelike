# 构筑版体验与验证 v0.2

本轮问题：第三关前玩家能否说出自己的构筑方向，战后是否期待下一次征募或整编。

第一屏先选关羽/周瑜/刘备，效果和提示同时展示；第一次战斗六选三，选牌立即显示攻势预览。每个组件一段明确效果，计分列出来源。每次战后免费征募与整编，避免等到后段才看到构筑变化。

桌面上方为五个组件槽，中间为选牌/出牌，下方为操作，左侧为关卡和资源，右侧为计分明细。1280×720须看见出牌按钮；较长日志和牌库独立滚动。普通键鼠输入，1–6选牌，Enter出牌/下一手，Esc关闭弹窗。

自动验证覆盖20组件的效果与交互、永久修改、经济原子性、随机重放、存档校验、三种开局模拟，以及浏览器完整胜败和桌面恢复。模拟只使用公开视图，不知道未来牌序。

五人试玩仍待进行，每人记录：

- 第一战是否理解兵力×倍率，以及为什么这手牌更强。
- 第三关前能否描述正在构筑什么，是否看懂奖励的配合价值。
- 是否出现存钱、即战力、成长和槽位之间的取舍。
- 通关/失败后是否主动想换核心再试；记录理由而非只问好不好玩。
- 每关、整局时长，以及首次困惑的位置。

当前原型的数值与随机池还未通过真人体验验收。Windows原生、正式美术、完整声音和Steam上传另列发行待办，不能用浏览器或模拟替代。
