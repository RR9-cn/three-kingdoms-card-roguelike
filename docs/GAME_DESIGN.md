# 午夜落槌：v0.9 藏品连锁

当前唯一运行版本是三场纯卡牌肉鸽验证版。卡牌自带点数与一句能力；收集和加点改变牌库。无炸金花牌型、贵宾席位、商店、现金与Boss规则。

## 每轮

抽六张，点击顺序决定三张出牌的左右位置，可用箭头调整。未选三张保留，下一轮补至六张；抽牌堆空后洗回弃牌。每场四轮、两次撤换，每次撤换1–3张。

热度从1开始。每次触发先累加卡牌点数，再执行能力；从左到右完成后，以累计点数×热度计分。无对子、顺子或同类牌型倍率。卡牌标签只有藏品、工具、诡物，用于具体能力。

镜子重触发左侧牌的完整能力，重复触发沿左侧递归，因此不会无限互触发。条件中的位置指本轮三张固定位置；点数指原始点数加升级。第一位无左侧牌，相关效果不发动。木槌只统计发动前已发生的额外触发；后续重触发不会追溯增加前面木槌的收益。

例如6点银币→2点镜子→4点木槌：点数6+2+6+4=18，木槌见一次额外触发使热度1+1=2，成交36。换成木槌→银币→镜子，银币因左侧4点小于自身6点获得2热度，镜子让银币再获得2热度，成交18×5=90。

红手套以50%概率重触发左侧牌。保底预览不模拟这次概率，实际事件在结算揭晓。动画可跳过；完整流水显示谁触发谁以及每一步点数、热度。

## 收集与加点

12种卡牌，10张起始实牌：古瓶×2、银币×2、长明烛×2、镜子、木槌、假面、账簿。前两场胜利后随机提供三种不同卡牌，选择一张加入收藏，再选择收藏中的任意实牌+2点；重复卡可以单独升级。升级影响低点、高点与相邻点数条件，可能使原组合失效。

三场目标暂定150、260、420，数值是待真人试玩的假设。每场累计达标即获胜，最后一轮优先判断胜利。第三场后展示通关和单轮纪录，可开启新种子重玩。

## 存档与验证边界

唯一协议为trigger-1，浏览器存档键midnight-hammer:trigger-1；不读取旧版本存档。随机状态可保存复现，预览不推进随机。AI协议schemaVersion 2只返回公开手牌与收藏，不返回抽牌顺序。

此版本用于验证收集与顺序构筑；三场通关不代表完整Steam内容量。自动策略只作为回归证据，不能替代真人对探索欲和反馈的判断。
