# 自由构筑规则轴诊断 v0.8

## 目的

本轮不修改贵宾、公式、关卡、经济或策略代码，只检查现有触发条件在缺少当前主流组件时是否仍有构筑价值。游戏继续采用自由构筑，测试中的分组不是套装、推荐配方或玩家可见流派。自动策略只读取公开局面；结果用于回归诊断，不代表真人胜率或乐趣。

## 两层测试

第一层让 16 位活跃贵宾分别作为固定开场，沿各自现有购买偏好运行相同的 100 个种子，共 1,600 局。该层允许购买全部活跃贵宾，用来观察策略最终会向哪里收敛。

- 总胜局：409/1,600，胜率 25.6%。
- 不含策展人的胜局：216；含策展人的胜局：193。
- 各开场策略胜率从 6% 到 71%，说明随机开场的总胜率不能代替流派对照。
- 这组自动策略和真人式随机开场策略不同，因此不能用“不含策展人胜局很多”反驳此前 150 局中胜局全部含策展人的观察。

第二层为每个规则轴固定一名能触发它的开场贵宾，并暂时禁止购买一组无关贵宾；每个规则轴运行相同的 200 个种子。这是消融压力测试，用于观察缺少策展人等当前主流组件时能否跨过第 7、8 场。名单只服务于隔离变量，而且禁止购买会降低货架有效选项，因此结果既不是自然成型概率，也不定义哪些贵宾必须一起出现。

## 结论

这些规则轴不是十条预设流派。成对藏品、低估值、同类别和年代序列直接改变六选三；追加竞价把它们连接到逐件响应；高估值、经济精简、传世三件套和最后一轮分别改变放大、经营、上限与出手时机。最终构筑应当跨轴组合，同一位贵宾也应有多个合理伙伴。

成对藏品相关组合已经可以在不依赖策展人的情况下通过第 7 场；同类别在开放购买时会吸收大量通用强件。最明确的弱关系仍是“选择三种类别”带来的牺牲与回报不对等，但任何调整都应让异域商能与多个现有开价、经营或压轴效果组合，而不是把它规定为编目师的固定终结件。

后续正式统计应回到开放购买：对胜局按实际触发、最终贵宾共现和关键替换进行事后聚类，报告不同组合结构的数量、策展人依赖率和第 7 场通过率。封闭消融只用于确认某条规则关系是否完全没有支撑能力。

## 停止条件

- 保留实验：开放购买下出现多种不含策展人的胜局结构，异域商与不止一种开价或经营效果共同跨过第 7 场，且总胜率没有异常跃升。
- 继续修正：只有极少数高爆发样本通关，路线中位成交能力仍停在第 7 场目标以下。
- 撤销实验：新效果主要增强一套固定组合、继续增强含策展人的混合好牌堆，或让三类别成为无条件最优选择。
