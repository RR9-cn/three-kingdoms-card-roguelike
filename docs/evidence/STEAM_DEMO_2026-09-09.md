# Steam 方向首章开发版验证 · 2026-09-09

本轮完成 Steam-first 产品迁移、可玩界面、征程流程和 Electron 桌面封装。当前可用于本地试玩，不是正式发行验收。

## 已有证据

- `npm test`：34 项通过。包括基础牌型全部 7,140 手枚举、行动与随机数、AI 可见信息、伤害与死亡、事务原子性、存档恢复与写入失败。
- `npm run test:browser`：4 项通过，Google Chrome。教学、单战失败、教学战胜利、正常八层征程胜利、中途刷新恢复、键盘操作；1280×720 和 1440×900 截图。校验底部决断按钮在 720 高视口内。
- `npm run build`：TypeScript 和 Vite 生产构建通过。CSS 为本地独立文件，避免开发态动态注入被 CSP 拦截；构建时存在相对 public CSS 路径提示，运行时样式读取已验证。
- macOS arm64、Windows x64 打包成功，Electron 44.3.0、Packager 20.3.0 锁定。Windows 尚未实机启动。
- macOS 桌面离线载入、渲染进程无法访问 `require`、最小化暂停、退出后恢复同一局面通过。最终打包程序验证结果另见 `desktop-smoke.json`；该文件的 `packaged` 明确标识是否为打包程序。
- 暂停通知通过受限 preload 单向回调传入，不暴露文件系统或任意 IPC。主进程同时监听 blur/minimize；当前自动化可靠触发的是原生 minimize，独立 blur 行为仍需补人工验证。

## 初步策略实验

四种固定策略各运行相同 1,000 个种子，原始数据 `simulation.json`。

| 策略 | 通关 | 平均交锋轮数 |
|---|---:|---:|
| 直接亮阵 | 75/1000 | 14.943 |
| 每轮加压至3 | 186/1000 | 13.497 |
| 散阵换低牌、顺势改善牌型；有组合加压 | 697/1000 | 15.842 |
| 同样凑牌，但散阵撤退 | 675/1000 | 18.207 |

这些策略只消费玩家合法视图。同一路线偏好、跳过奖励，不涉及隐藏牌序，也不代表充分使用锦囊与军宝的最优策略。结果支持继续测试换阵与微调的决策价值，不能推导真人胜率、加压已平衡或商业表现。没有依据这轮实验修改数值或存档版本。
