# v0.7 简明计分验证

## 玩家可见规则

基础攻势统一为：**三张牌点数之和 × 阵型倍率**。

| 阵型 | 条件 | 倍率 |
|---|---|---:|
| 散阵 | 不满足其他阵型 | ×1 |
| 合击 | 两张同点数 | ×2 |
| 连阵 | 三张点数连续 | ×3 |
| 同袍 | 三张同兵种 | ×4 |
| 同袍连阵 | 同兵种且连续 | ×6 |
| 三军同心 | 三张同点数 | ×10 |

例如7、7、2组成合击，基础攻势为（7+7+2）×2=32。阵型升级只让对应倍率+1。将星栏位置不影响算分，结算采用固定效果顺序。

## 自动平衡检查

使用公开状态贪心选牌、固定核心偏好、不换牌、不开加压的保守脚本，每个开局核心运行200个相同种子。关羽通关185局（92.5%），周瑜131局（65.5%），刘备194局（97%）。八关目标为100、220、320、600、950、1350、1800、1900。

脚本只检查新分数量级能否完成征程，不代表真人胜率，也不能证明规则已足够好玩。详细原始结果见 [forge-simulation.json](forge-simulation.json)。
