# 异域商三类别缩放配对实验 v0.8

## 结论

**否决`当前热度 ×1.8`，正式规则继续使用`三种类别：+4热度`。**

候选规则提高了通关率并增加了无策展人胜局，但没有改善六选三的选择空间。它让异域商变成新的高覆盖核心，并与淘金客、估价师的加法成长形成通用乘算收尾。这会把“自由组合”收敛为“先堆热度，再拿异域商”。

## 方法

- 接口：`simulate_open_ecology`
- 局数：基线500局，候选500局
- 种子前缀：`sunquan-paired-v08`
- 策略：同一套`adaptive-open`
- 唯一变量：`sunquanMode`从`add-four`变为`times-1.8`
- 近优阈值：当前最高保底成交价的90%

正式内容、存档和桌面端均未切换到候选规则。

## 核心结果

| 指标 | `+4热度` | `当前热度 ×1.8` | 变化 |
| --- | ---: | ---: | ---: |
| 通关 | 162/500 | 222/500 | +60 |
| 通关率 | 32.4% | 44.4% | +12.0个百分点 |
| 通过第7场 | 267 | 315 | +48 |
| 无策展人胜局 | 48 | 93 | +45 |
| 明显单解率 | 55.3% | 56.7% | +1.4个百分点 |
| 有意义替代率 | 22.0% | 19.3% | -2.7个百分点 |
| 平均近优组合数 | 1.939 | 1.848 | -0.091 |
| 平均因果签名数 | 1.268 | 1.225 | -0.043 |

候选规则下玩家更容易过关，但每手反而更容易出现一个显然的最优答案。

## 后期选择

| 指标 | `+4热度` | `当前热度 ×1.8` |
| --- | ---: | ---: |
| 后四场明显单解率 | 54.7% | 55.1% |
| 后四场有意义替代率 | 23.3% | 20.3% |
| 第7场明显单解率 | 56.3% | 54.2% |
| 第7场有意义替代率 | 22.8% | 19.5% |

第7场的明显单解率略有下降，但有意义替代率同时下降，近优组合也从2.017降至1.898。这不是更多可行选择，而是候选规则改变了分数差距的分布。

## 新的收敛

| 指标 | `+4热度` | `当前热度 ×1.8` |
| --- | ---: | ---: |
| 异域商最终留席率 | 54.0% | 61.2% |
| 异域商留席时胜率 | 27.8% | 51.0% |
| 异域商胜局覆盖率 | 46.3% | 70.3% |
| 三类别轴胜局数 | 72 | 151 |
| 三类别轴胜局覆盖率 | 44.4% | 68.0% |
| 淘金客胜局覆盖率 | 82.1% | 83.8% |

无策展人胜局的增加主要来自异域商接替了乘算核心的位置，而非多条独立路线同时获得竞争力。候选规则下，异域商、淘金客和估价师频繁共同出现在高频最终构筑中，与预先设定的“不得形成新唯一答案”停止条件冲突。

## 决策

1. 不修改正式异域商文案和数值。
2. 保留`sunquanMode`作为本地瞬时评测参数，便于复现这次否决。
3. 不继续为这个方案微调倍率。当前缺口是“一手牌有多个不同因果的好答案”，继续改乘数只会把一个轴做得更强。
