# 编目师序列构筑配对验证

本轮只把编目师从“序列最低价拍品追加竞价一次”改为“序列三件拍品各追加竞价一次”。关卡目标、资源、货架、其他贵宾数值和策略均保持相同。评测器同时补齐16位活跃开场贵宾的构筑偏好，并修复题材改名后策展人触发统计失效的问题。

## 配置

- 16位活跃贵宾分别作为固定开场。
- 每位开场使用50个相同种子配对比较。
- 旧规则800局，新规则800局，共1600局。
- `counterplay`公开状态策略；结果用于回归诊断，不代表真人胜率。

## 结果

| 指标 | 旧规则 | 新规则 |
|---|---:|---:|
| 总胜局 | 165 / 800（20.6%） | 206 / 800（25.8%） |
| 不含策展人的胜局 | 88 | 123 |
| 含编目师的胜局 | 47 | 88 |
| 编目师且不含策展人的胜局 | 30 | 65 |
| 编目师与策展人同时出现的胜局 | 17 | 23 |

新规则增加了41个总胜局，其中35个是不含策展人的胜局。编目师独立于策展人通关的样本增加一倍以上，说明序列强化主要扩大了独立路线，而不是只放大同类别构筑。当前证据支持保留三件分别追加的规则；暂不调整关卡目标或其他贵宾。
