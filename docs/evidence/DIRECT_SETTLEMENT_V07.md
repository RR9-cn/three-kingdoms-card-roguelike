# v0.7 战后押分移除验证

战后“鸣金收兵／乘胜追击·押20%”选择已移除。马超的35%连锁追击保持原样，本手随机连锁揭晓完成后，最终攻势自动全额入账。

## 玩家流程

1. 玩家六选三并出牌。
2. 结算按原有步骤揭晓，因果链和将星高亮继续播放。
3. 动画完成、跳过动画或启用减少动态效果时，本手攻势自动入账一次。
4. 页面显示本手入账值和剩余目标，只保留下一手、查看战报或收取战果按钮。

旧版本的待入账存档在继续征程时自动全额入账；已经押注成功或失败的旧结果保留原有分数。新流程不再消耗押分使用的随机流。

视觉证据：[burst-direct-settlement.png](burst-direct-settlement.png)

## 验证结果

- 单元测试：43项通过。
- 浏览器测试：9项通过，包括普通动画、跳过、减少动态效果、旧结果恢复和完整八关征程。
- 200局×3开局模拟结果与删减前一致：关羽89.5%、周瑜52.5%、刘备63.5%。
- macOS arm64与Windows x64交叉打包通过。
- macOS arm64打包应用的完整征程、极限挑战、暂停和重启恢复通过。

Windows结果是交叉打包产物，仍不代表Windows原生运行验证。
