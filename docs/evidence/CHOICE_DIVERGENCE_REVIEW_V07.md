# v0.7 选牌分歧人工审核

本结论基于 `choice-divergence-v07` 的400组六张手牌，只检查未整编基础牌库与确定性预览。它用于选择下一项小实验，不是武将强度或真人胜率结论。

## 结论

当前自由组合已经改变部分选牌，但整体分化仍然有限。12种单将构筑面对同一手牌时，平均只产生2.88种最优三张；任意两种单将构筑有72.7%的样本共享至少一个最优选择。

刘备最明确地改变玩家对手牌的估值：加入不同零至双将上下文后，有69.6%的样本更换了全部最优三张。貂蝉为37%，周瑜为29.1%，说明低点、谋牌和同兵种已经能够形成可观察的选牌方向。

陆逊与诸葛亮是下一轮最值得检查的两名将星。陆逊在具有额外计分来源的上下文里带来明显确定增幅，但总体只改变12%的最优选择；诸葛亮平均提高58.79%确定得分，但只改变13.1%的最优选择。它们更容易增强玩家本来就会选择的牌，而不是提出另一种选法。

关羽、张飞、孙策和赵云也较少改变最优选择，但当前得分增幅较低或依赖明确阵型，不应与前两名同时修改。马超的价值来自出牌后的隐藏追击，曹操来自换牌经济，荀彧来自整编后的牌库规模，均超出本次即时选择指标，不能按0%结果判断。

## 下一实验边界

第二阶段只围绕陆逊与诸葛亮设计一个A/B方案，目标是提高它们对六选三的影响，同时继续复用“额外计分”和现有手牌位置。基础公式、其他十名将星、关卡、Boss、奖励、整编、演出和存档全部冻结。

进入实现前，方案必须能回答：面对同一组六张牌，为什么玩家会因为持有该将星而放弃原本最高的三张？如果只能回答“同一手分数变高”，方案不进入代码。

保留条件是固定样本中选牌改变率提高，且人工试玩能说出实际放弃了什么；若只能制造新的固定答案或需要新增名词与阶段，则撤销方案。
