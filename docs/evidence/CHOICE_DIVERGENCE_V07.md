# v0.7 选牌分歧诊断

- 内容版本：0.7.0
- 固定种子：`choice-divergence-v07`
- 六张手牌样本：400
- 比较构筑：299（零至三名将星）

## 边界

- 未整编的36张基础牌库；每个样本抽取六张公开手牌。
- 第1关中性战斗状态、零成长、零阵型升级、零军资，不包含Boss与换牌。
- 只使用正式确定性预览；不抽取马超追击等出牌后隐藏随机结果。
- 报告用于定位人工审核候选，不代表强弱平衡结论或真人选择预测。
