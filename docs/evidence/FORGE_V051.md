# v0.5.1 随机战后整编验证

日期：2026-09-10。目标是降低战后页面的决策密度，将六种整编方式与整副牌库选择收拢为一次随机正向结果。

## 实际规则

- 胜利后的整编页只有“请军师整编”和“暂不整编 +3军资”两个行动。
- 接受时，从募兵、练兵、精锐、研习四类合法结果中等概率抽取一类，再随机合法目标。
- 募兵复制随机阵牌并创建新ID；练兵使随机未满9点阵牌点数+2；精锐使随机阵牌+12兵力；研习使随机牌型等级+1。
- 满60张时排除募兵；没有9点以下阵牌时排除练兵。删牌和改兵种不进入随机池。
- 商店顶部显示本次具体结果；离开商店后清除提示。结果、随机状态与商店货架一同保存。
