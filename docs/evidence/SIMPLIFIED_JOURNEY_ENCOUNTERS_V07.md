# 基础征程关卡节奏验证（v0.7）

本轮只调整基础八关的关卡职责。第1、2、3、5、6、7关改为纯分数目标，第4关张宝与第8关张角保留规则变化。目标、奖励、经济、武将、计分和Boss行为均未调整；原有高点减免、普通疑阵和首牌兵种限制代码继续保留，供未来高难度或Boss规则使用。

## 验证结果

- 48项核心测试通过，明确断言八关规则序列为 `none, none, none, ambush, none, none, none, last-stand`，目标仍为180、220、320、600、950、1350、1800、1900。
- 10项浏览器测试通过，固定种子完整走完八关，张宝和张角的阶段变化继续生效。
- 600局固定启发式模拟：关羽125/200、周瑜104/200、刘备115/200通关。相对上一版只有小幅波动，没有开局路线失效。
- macOS arm64和Windows x64重新打包成功；macOS打包版通过完整征程、极限挑战、暂停与重启恢复冒烟测试。

自动策略只用于回归检查，不代表真人胜率或最终难度结论。下一步应通过真人试玩判断普通关是否提供了足够的构筑释放空间，以及两个Boss是否因此更有辨识度。
