# v0.7 结算因果链验证

## 验证目标

只改善出牌后的因果可读性，不修改计分、随机、关卡、武将能力或玩家行动。中央战斗区显示当前或最近一次已经揭晓的链条，例如“马超 → 枪7额外计分 → 太史慈 → 黄忠 → 陆逊 → 马超未追击”。

## 结果

- 因果链完全由现有 `Score.steps` 推导，没有增加存档或规则状态。
- 动画每揭晓一步才增加对应节点；尚未揭晓的追击结果不会提前出现。
- 新一次额外计分会开始新的短链，下一张普通阵牌出现后保留刚完成的链，便于玩家回看。
- 跳过动画和系统“减少动态效果”会立即显示完整已结算链；右侧逐项账本继续存在。
- 1280 × 720 画面中，六节点链、手牌、结算结果与 Boss 战斗区均保持可见，没有横向溢出。战后押分已在后续版本移除。
