# v0.7 陆逊与诸葛亮选牌实验（已撤销）

本实验使用与 `choice-divergence-v07` 相同的400组六张手牌，并用现有征程脚本各运行200个相同种子。实验只修改陆逊与诸葛亮，最终未进入玩家版本。

## 第一轮：高补偿条件

- 陆逊：只响应本手最高点牌的额外计分，每次+6倍率。
- 诸葛亮：最右阵牌未被其他将星覆盖时，额外计分两次。

陆逊的选牌改变率由12.0%升至20.1%，诸葛亮由13.1%升至28.0%，但诸葛亮的确定得分平均增幅从58.79%升至165.15%。征程中关羽、周瑜、刘备开局脚本胜率分别为98.5%、40%和95%，强度与开局差异明显失衡。

## 第二轮：收紧补偿

- 陆逊条件不变，每次改为+4倍率。
- 诸葛亮条件不变，只额外计分一次。

陆逊选牌改变率为16.96%，诸葛亮为19.18%，但整体单将构筑共享最优选择仍为72.7%，与基线相同。征程中三个开局脚本胜率分别为88%、15.5%和21%；基线为89.5%、52.5%和63.5%。

## 结论

给通用连锁桥梁增加排他条件，能够略微改变这两名将星自己的选牌，却没有提升整体构筑分化，并显著破坏现有构筑强度。继续调整补偿数值只会在“更有条件”和“恢复旧强度”之间反复加减，因此撤销两项改动。

本次结果否定的是这两个具体方案，不是否定“构筑应改变选牌”的目标。下一步不继续修改陆逊与诸葛亮，也不为这次失败调整关卡目标。
