# v0.9 藏品连锁验证

## 已实现

唯一入口为纯卡牌构筑。12种模板、10张起始牌，顺序六选三，点数×热度，重触发完整能力，保留未选牌，两次撤换，三场目标。前两场胜利各收集一张并任选实牌+2点。新版AI协议2使用同一规则内核。

用户明确要求删除旧版，因此删除贵宾/牌型内核、旧AI评测与UI资源、旧测试、旧请求样例和本地旧打包产物。历史设计规格和实验报告仅留档；没有旧版运行入口。

## 验证结果

- 11项核心/接口测试：精确示例、排序、递归能力、概率预览隔离、非法操作原子性、入账一次、保留补牌、奖品升级、防重复、终局胜负、存档、AI完整会话。
- 3项Chrome测试：从首页按公开手牌完成三场、两次奖励升级、结算中刷新恢复、排序与撤换、1000px宽无横向溢出、无效存档回退。
- macOS Electron冒烟：启动、外链样式加载、出牌、跳过结算、刷新恢复相同69分结果。
- 类型检查与生产构建通过。Windows原生运行未测试。
