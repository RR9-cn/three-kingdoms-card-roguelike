## Context

异域商当前在三种类别时固定增加4热度。该效果前期强、后期不随其他热度成长；候选`×1.8`前期更弱，但会放大现有成长与逐件效果。两者都复用现有三类别条件和热度，不增加玩家概念。

## Goals / Non-Goals

**Goals:**

- 在相同开放生态种子上隔离比较两种异域商结果。
- 同时观察通关、策展人依赖、三类别使用与选择深度。
- 默认模式与正式游戏保持完全一致。

**Non-Goals:**

- 不在得到结果前修改公开文案或正式数值。
- 不同时调整关卡、其他贵宾、价格或稀有度。

## Decisions

`ForgeTuning`增加`sunquanMode`，默认`add-four`，候选为`times-1.8`。计分顺序保持现有位置：逐件加热度与老鉴定师成长结算后应用异域商，因此候选明确测试后期缩放能力。

`simulate_open_ecology`接受现有`overrides`对象并把调参传给策略预览、选择深度、实际结算和货架生成。两份请求使用相同种子前缀和局数，结果按总体与关键指标人工配对比较。

## Risks / Trade-offs

- [候选会放大淘金客和估价师并形成新收敛] → 单独检查无策展人结构及贵宾胜局占比，出现新唯一答案即否决。
- [早期削弱导致总胜率下降] → 分关卡检查，不能只看最终胜率。
- [自动策略随候选改变购买行为] → 这是开放生态的预期结果；相同策略函数与种子保持不变。
