## Context

全部22位人物继续保留稳定ID以恢复旧存档，但新局只从12位活跃将星中征募和购买。当前随机整编同时选择类型和目标，玩家无法围绕已有构筑改造牌库。

## Goals / Non-Goals

**Goals:**

- 用更少内容形成三套能改变选牌与改牌行为的构筑。
- 每场整编只展示一个随机结果，同时保留一次清楚的目标选择。
- 保持基础规则与旧存档兼容。

**Non-Goals:**

- 不增加新资源、战斗操作或构筑槽位。
- 不删除押分和稀有度系统。
- 不在本轮完成全量平衡结论。

## Decisions

### 12位活跃名单

对子追击由关羽、张飞、马超、陆逊构成；低点精兵由刘备、诸葛亮、曹操、荀彧构成；同袍改编由周瑜、貂蝉、孙策、赵云构成。三组分别偏向对子与概率连锁、保留低点并裁减牌库、改造兵种并追求同袍连阵。

### 保留22个定义但限制奖励池

稳定ID与效果继续存在，旧v8存档可以恢复；`COMPANION_IDS` 只暴露12位活跃将星供新局抽取。这样无需存档迁移，也不会让退役人物进入新奖励。

### 先揭晓类型，再选择目标

随机池包含裁军、募兵、练兵、精锐、改编和研习。揭晓后状态保存，重启不能重抽；玩家只处理当前一种方式。完成目标选择后才进入商店并增加整编统计。

## Risks / Trade-offs

- [内容量看起来减少] → 用首页与内容页明确三套发动机，优先验证差异而非数量。
- [旧存档可能持有退役将星] → 继续渲染和结算全部稳定ID，只限制新获得池。
- [目标选择重新增加操作] → 每次只展示一种动作和合法目标，不恢复六标签操作台。
