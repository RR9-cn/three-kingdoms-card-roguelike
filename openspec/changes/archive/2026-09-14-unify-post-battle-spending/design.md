## Context

现有胜利流程固定发放免费三选一武将，再免费揭晓一种整编，最后进入出售武将的商店。招募与商店重复提供武将，招募和整编又都是无成本强化，因此玩家只是在连续领取奖励。现有商店、随机整编池、军资和目标选择均可复用。

## Goals / Non-Goals

**Goals:**

- 让所有战后永久强化通过军资产生机会成本。
- 删除新流程中的独立免费招募阶段和放弃补偿。
- 先公开整编类型，再由玩家决定是否支付。
- 保持旧存档可完成当前阶段。

**Non-Goals:**

- 不修改武将或整编效果。
- 不为不同整编设置不同价格。
- 不增加整编刷新、预付随机或新的战后资源。
- 不重做商店视觉风格。

## Decisions

1. 每场胜利直接准备商店：结算收入、抽取3名武将、从合法整编中抽取1种并公开。相比“招募与整编二选一”，统一商店让军资成为唯一取舍尺度，也删除一个完整阶段。
2. 整编固定8军资。玩家在看到类型后点击购买，扣款并进入现有目标选择界面；完成后返回原商店，保留武将货架与刷新次数。先扣钱再揭晓会把选择变成赌博，因此不采用。
3. 商店中的 `pendingEdit` 表示尚未购买的整编报价；进入 `forge` 后表示已购买、等待选择目标；完成后置空，确保每关最多一次。离开商店时未购买报价直接清空。
4. `recruit` 和旧 `forge` 存档仍可读取。旧招募选择完成后进入新商店；旧已揭晓的免费整编可以完成，随后进入商店。新状态转换不再创建这些免费阶段。

## Risks / Trade-offs

- [将星获取速度显著下降] → 第一关后收入通常足以购买至少一名将星，模拟完整征程并观察构筑可行性。
- [固定8军资使不同整编价值不等] → 先保持单一价格，价值差异本身形成买或不买的选择；不增加价格表。
- [旧阶段继续存在于代码] → 只作为存档兼容路径，自动测试确保新征程不会进入免费招募。

## Migration Plan

不提升存档结构版本。新胜利流程直接进入商店；处于 `recruit` 或 `forge` 的旧存档可完成当前页面，此后进入统一流程。回滚时恢复原阶段转换即可。
