## ADDED Requirements

### Requirement: 评测区分序列独立成型

系统 SHALL 在批量构筑诊断中报告编目师的最终持有与胜局，并区分包含策展人与不包含策展人的胜局。

#### Scenario: 比较序列规则
- **WHEN** 调用者用相同种子比较单牌追加与三牌追加的编目师规则
- **THEN** 报告包含总胜率、编目师胜局、无策展人胜局和两者共同出现的胜局

### Requirement: 随机开场策略覆盖活跃贵宾

系统 SHALL 为当前16位活跃开场贵宾提供与其公开能力相关的购买方向，不得把新增开场贵宾统一退回旧三位之一的默认偏好。

#### Scenario: 新活跃贵宾成为开场贵宾
- **WHEN** 自动策略以估价师、异域商、黑金侯或守夜人开始一局
- **THEN** 其购买排序包含与高估值、混合类别、三件套或压轴相关的现有贵宾，而非统一使用老鉴定师排序
