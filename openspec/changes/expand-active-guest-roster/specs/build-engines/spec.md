## MODIFIED Requirements

### Requirement: 活跃名单支持自由组合

系统 SHALL 只在新局商店中提供16位活跃贵宾，并 SHALL 让玩家能用现有的成对藏品、低估值、同类别、年代序列、传世三件套、最后一轮和追加竞价规则自由组合开价、响应、成长与爆发效果。

#### Scenario: 查看活跃贵宾
- **WHEN** 玩家在新局中持续购买和刷新贵宾
- **THEN** 候选只来自16位活跃名单，其中包含估价师、异域商、黑金侯与守夜人

#### Scenario: 旧存档持有非活跃人物
- **WHEN** 玩家载入含有其他稳定人物 ID 的 v8 存档
- **THEN** 人物仍可显示和结算但不会进入新的奖励池
