## Context

现有公式先给每种阵型一份基础兵力，再加牌点和组件，阵型升级同时增加兵力与倍率。整手组件按照持有位置执行，使加倍率与乘倍率的顺序产生差异。玩家必须理解多个来源，才能预测一手牌。

## Goals / Non-Goals

**Goals:**

- 让新玩家用一句公式预测没有组件时的结果。
- 让阵型差异只由容易比较的倍率表达。
- 让组件持有位置只承担展示，不成为隐藏算分规则。
- 保持追击和Boss等已经验证的内容可以组合。

**Non-Goals:**

- 本轮不重做22个组件的功能定位。
- 不增加新的奖励、资源、货币或局外成长。
- 不改变炸金花式六种牌型的判定。

## Decisions

### 点数从牌本身开始

计分初值为0点数，逐张加入牌面点数与永久强化。阵型只提供倍率：散阵1、合击2、连阵3、同袍4、同袍连阵6、三军同心10。这样基础手牌可直接心算。

### 阵型升级只加倍率

牌型等级每升一级只增加1倍率，不再同时增加固定点数。随机整编仍可抽到阵型升级，但描述和效果只有一个维度。

### 组件采用固定语义顺序

逐牌效果仍在对应牌计分时发动。整手加点数和加倍率效果按固定规则计算，所有乘倍率效果最后计算。组件在麾下栏的排列不改变结果，界面和行动协议移除左右移动。

### 使用新存档命名空间

计分和行动协议属于破坏性规则变更，采用schemaVersion8、contentVersion0.7.0和独立v8双槽，保留旧v7存档。

## Risks / Trade-offs

- [早期分数显著下降] → 用模拟和完整征程调整八关目标，而不是重新增加基础点数。
- [部分加点数组件相对变强] → 保留第一版组件数值，先从模拟结果识别极端组合。
- [移除排序减少高手空间] → 把深度保留在选牌、换牌、组件取舍和追击，而不是结算顺序知识。
- [删除历史原型后不能在当前构建内直接对比旧玩法] → 过去实现仍可通过 Git 历史查看。
