## Why

三局人工试玩已经证明自由将星连锁能形成构筑感，但尚未证明不同构筑会让玩家面对同一手六张牌时作出不同选择。现有胜率模拟只回答能否通关，无法识别万能组件、无决策价值的被动效果或所有构筑收敛到同一最优三张的问题。

## What Changes

- 增加只供开发使用的选牌分歧分析器，在相同公开六张手牌上比较多组代表性将星构筑的最优三张。
- 报告构筑之间的选牌一致率、各阵型与触发来源的集中度、最优与次优选择差距，以及单名将星加入前后改变最优选择的频率。
- 生成机器可读 JSON 和便于策划审核的 Markdown 结论，明确下一轮最多需要检查的一至两名将星。
- 固定种子与输入样本，使报告能够在规则未变时稳定复现。
- 不修改正式游戏规则、武将池、数值、界面、存档和随机流程。

## Capabilities

### New Capabilities

- `choice-divergence-analysis`: 使用公开规则比较不同构筑在相同手牌上的选择差异，并产出可复现的内部诊断报告。

### Modified Capabilities

无。

## Impact

新增 `tools/` 下的内部分析程序、对应的单元测试、npm 命令与 `docs/evidence/` 报告。分析器复用现有纯 TypeScript 计分预览，不接入浏览器或 Electron，也不改变任何玩家可见行为。
